## 📂 精選項目

### 1. 🎮 Alien 5-in-row（五子棋 AI）

一個有外星科技風格嘅五子棋遊戲，內置 **Minimax 演算法 + Alpha-Beta 剪枝** AI。

**技術重點：**
- 用 Pygame 實現完整遊戲循環、粒子效果、光暈動畫
- AI 使用啟發式評估（活四、衝四、活三、眠三等棋型評分）
- 支援手機自適應、音效、勝率統計、難度選擇

**學到嘅嘢：**
- 遊戲 AI 嘅決策邏輯
- 即時渲染同效能優化
- 用戶體驗設計（UX）

### 2. ♟️ Chess AI（國際象棋）

一個完整嘅國際象棋遊戲，玩家揸白棋，電腦揸黑棋，AI 約 **1000 ELO**。

**技術重點：**
- 完整實現所有國際象棋規則：易位、吃過路兵、升變、50 回合和棋
- AI 使用 **NegaMax + Quiescence Search + Piece-Square Table（PST）**
- 支援手機自適應、Canvas 向量棋子繪製、升變對話框

**學到嘅嘢：**
- 複雜狀態管理（castling rights、en passant）
- 搜尋演算法嘅實際應用
- 跨平台 UI 設計
