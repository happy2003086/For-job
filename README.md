## 精選項目

### 1. Alien 5-in-row（五子棋 AI）
一個有完整 UI 同特效嘅五子棋遊戲，內置可調節難度嘅 AI。

**技術重點：**
- Pygame 實現遊戲循環、粒子效果、光暈動畫
- AI 使用 Alpha-Beta 剪枝 + 啟發式評估（活四、衝四、活三、眠三等棋型評分）
- 支援勝率統計、難度選擇、最後一步提示

**學到嘅嘢：** 遊戲 AI 決策邏輯、即時渲染優化、用戶體驗設計
線上試玩：https://funny-liger-6d97e6.netlify.app/

### 2. Chess AI（國際象棋）
完整規則嘅國際象棋，玩家揸白棋，電腦約 1000 ELO 水平。

**技術重點：**
- 完整實現易位、吃過路兵、升變、50 回合和棋規則
- AI 使用 NegaMax + Quiescence Search + Piece-Square Tables
- 用 Canvas 向量方式繪製棋子（唔依賴圖片或字體）

**學到嘅嘢：** 複雜狀態管理、搜尋演算法應用、跨平台 UI 設計

---

### 3. Minesweeper（踩地雷）
經典踩地雷遊戲，支援手機觸控操作。

**技術重點：**
- 動態計算格子大小，自動適配不同屏幕
- 遞迴翻開空白格、第一次點擊保證安全
- 完整插旗同勝利判定邏輯

**學到嘅嘢：** 遞迴演算法、觸控事件處理、遊戲狀態機

---

### 4. Sudoku Solver（數獨求解器）
用 Tkinter 寫嘅數獨求解器，支援手動輸入同即時驗證。

**技術重點：**
- 回溯法（Backtracking）求解
- 完整輸入驗證同錯誤提示
- 3×3 區塊視覺化

**學到嘅嘢：** 回溯演算法實際應用、GUI 佈局設計

---

### 5. Pong（乒乓球）
經典雙人 / 人機對戰乒乓球遊戲。

**技術重點：**
- 碰撞偵測、分數系統、簡單 AI 對手
- 流暢遊戲循環同鍵盤控制

**學到嘅嘢：** 基礎遊戲物理、即時輸入處理
